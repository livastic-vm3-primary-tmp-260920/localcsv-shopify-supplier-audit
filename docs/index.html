Open-source example, not a merchant service


This page hosts the exact self-contained JavaScript CSV preflight example from
its public MIT-licensed source.
It has no accounts, subscriptions, Shopify integration, telemetry,
external scripts or advertising. It is a client-side reference tool,
not an import or a commercial service. Its checks are advisory, and
they cannot replace Shopify's official import requirements.




Privacy and import limitations


This file includes only the pure local CSV and Shopify diagnostic JavaScript
engines. No tracking, external scripts, advertisers, analytics, network requests,
file uploads, merchant API login or subscription. It works with Wi-Fi disconnected.


Image URL syntax is reviewed but the URLs are not fetched. This tool never
updates Shopify. Keep the full product export, all relevant variant rows, and
dependent option columns. Spreadsheet formula protection is defense-in-depth;
it cannot guarantee safety in all spreadsheet programs.
