Worked example: compare supplier costs and product changes

A fictional clothing store has two T-shirt variants and one cap. The supplier has sent a CSV with unique SKU codes and unit costs, while the store has prepared a proposed export with an updated price for one variant and lower stock for the cap.

Try the workflow with three openly licensed, fictional sample CSV files: 1. current Shopify export, 2. supplier SKU list, 3. proposed export. Download or save each file, select it below, and choose Audit selected CSVs locally.

Raw supplier headers differ? Choose them, do not guess

Another fictional supplier file has the same three SKUs but uses Vendor Ref instead of SKU and Net Unit Price instead of Cost. Download the fake supplier with nonstandard headers. Choose it as your second file, click Show supplier column names locally, and explicitly type Vendor Ref and Net Unit Price in the two mapping fields. You can use this with two or three files. No automatic SKU synonym/size/colour matching or currency conversion is attempted. The original supplier CSV stays unchanged. The resulting supplier-joined and cost files are for review only, never Shopify imports.

공급업체 열 이름 직접 지정: 다른 공급업체의 CSV가 SKU 대신 Vendor Ref, 원가 대신 Net Unit Price라는 열 이름을 쓸 수 있습니다. 위 가상 CSV를 내려받아 두 번째 파일로 지정하고 열 이름 확인 버튼을 누르세요. 표시된 열 이름 두 개를 그대로 입력하면 브라우저 안에서만 검토용으로 매핑합니다. 상품 옵션·크기·통화·SKU를 자동 추측하지 않으며 원본 CSV를 변경하지 않습니다.

  • TEE-BLK-M: Price changes from 29.00 to 31.00; the variant remains.
  • CAP-WOOL: Inventory quantity changes from 7 to 6; the variant remains.
  • TEE-BLK-L: Unchanged. All three supplier SKUs match.

You should receive seven downloadable review files, including a field-by-field before/after diff, supplier match summary, unmatched exceptions, and two advisory product-CSV preflight reports. A seventh, strictly local CSV report estimates proposed price minus the supplier unit cost. This arithmetic assumes both inputs use the same currency and excludes shipping, taxes, advertising, returns and payment fees. It is NOT real profit. None of these outputs is an authorized Shopify import command. The supplier-joined report contains extra supplier-only fields and MUST NOT be used as a Shopify import CSV.

Supplier column names differ? / 공급업체 열 이름이 다르다면

Use the supplier file's exact original header names. The mapping is ONLY a temporary in-memory column-label rename: no guessed SKU, size, color, discounts, currency, or product equivalents. Leave both inputs empty when the supplier already uses an exact SKU and Cost/Unit cost column. Your original file remains unchanged.

If you enter one mapping field, enter BOTH. Exact matching only; duplicate/ambiguous SKU keys and colliding column names stop safely. These audit outputs must NOT be imported into Shopify.

In two-file mode, proposed-field change analysis is NOT run, and five review-only reports are generated. The third file can never be silently ignored. In three-file mode seven reports are generated.

Each CSV: under 2.2 MB, UTF-8 preferred. The SKU key must be unique and nonblank for comparison. Ambiguous data stops rather than silently guessing.

Choose two or three CSVs to begin. No data leaves your browser.

          Limits, security and official guidance

          For your privacy this downloadable single HTML includes only the open-source CSV parser, supplier SKU join, optional CSV diff and Shopify preflight algorithms. No network, telemetry, cookies, scripts from other sites, or Shopify API calls. Input is limited to protect browser performance; any ambiguous key stops safely. Advisory warnings cannot guarantee Shopify import success.

          Shopify explains URL handles, variant option dependencies and CSV imports in its official product CSV guide. Keep backups and independently review official import requirements.
