Offline Shopify supplier SKU change audit

Compare three CSV files: your current Shopify product export, a supplier SKU/cost list, and a separately prepared proposed Shopify product CSV. Check SKU matches, added/removed and changed variants, and advisory errors before considering an import. Nothing is sent to a server.

한국어: 기존 Shopify 상품 CSV, 공급업체 SKU/원가 CSV, 변경 예정 상품 CSV를 각각 선택하면 브라우저에서 SKU 대응·변경사항·상품 데이터 오류를 비교합니다. 서버 업로드, 회원가입, 앱 설치, 광고가 없습니다.

Backup before editing. This tool does not create a safe Shopify import file or modify your products. Shopify updates depend on URL handles and related variant option fields, not only SKU. Supplier-joined reports include extra Cost/Supplier columns and must NEVER be imported into Shopify. Keep confidential supplier costs and customer data private. Test one or two products using Shopify's official process first.

Worked example: compare supplier costs and product changes

A fictional clothing store has two T-shirt variants and one cap. The supplier has sent a CSV with unique SKU codes and unit costs, while the store has prepared a proposed export with an updated price for one variant and lower stock for the cap.

Try the workflow with three openly licensed, fictional sample CSV files: 1. current Shopify export, 2. supplier SKU list, 3. proposed export. Download or save each file, select it below, and choose Audit three CSVs locally.

  • TEE-BLK-M: Price changes from 29.00 to 31.00; the variant remains.
  • CAP-WOOL: Inventory quantity changes from 7 to 6; the variant remains.
  • TEE-BLK-L: Unchanged. All three supplier SKUs match.

You should receive six downloadable review files, including a field-by-field before/after diff, supplier match summary, unmatched exceptions, and two advisory product-CSV preflight reports. None is an authorized Shopify import command. The supplier-joined report contains extra supplier-only fields and MUST NOT be used as a Shopify import CSV.

한국어 예제: 가상의 의류 매장 상품 3개를 공급업체 SKU로 비교합니다. 티셔츠 M 사이즈 가격 29.00 → 31.00, 모자 재고 7 → 6으로 변경됩니다. 위 CSV 예시 세 개를 내려받고 아래 파일 입력에서 각각 선택해 보세요. 6종 보고서는 검토용이며 Shopify에 자동 반영되지 않습니다.

    Limits, security and official guidance

    For your privacy this downloadable single HTML includes only the original open-source CSV parser, SKU join, CSV diff and Shopify preflight algorithms.
